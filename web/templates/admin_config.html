What a reload does

Reloaded immediately: alert channels (Teams/Slack/Discord/email/webhook URLs), maintenance-window predicates, retention threshold, status-page enable, metrics token, analytics target, browser timeout. App YAMLs are also re-read from disk.

Requires a full restart: the scheduler (cron expressions are bound to APScheduler at startup), auth settings (session signing, LDAP server connection, GitHub OAuth client), the bind port and CSRF/cookie attributes, and the database path.
